# Support

A2A Nexus is an alpha public-readiness project. Community questions and bug reports are welcome when access is available, but no production support, stability guarantee, repository visibility change, release, package publication, or deployment approval is implied.

## Questions and usage help

Open a GitHub issue in `jinwon-int/a2a-nexus` using the most relevant issue template when you have repository access. Keep examples local-only and redact private endpoints, provider IDs, Telegram IDs, host paths, and credentials.

## Bugs

Use the Bug report template. Include local reproduction steps and redacted evidence only.

## Security issues

Do not open public issues for vulnerabilities. Follow `SECURITY.md` and use GitHub private vulnerability reporting when available. If no private route is available, open only a non-sensitive maintainer-contact request; do not include vulnerability details until a maintainer provides a private route.

## Unsupported requests

This repository does not authorize production deploys, service restarts, DB/outbox mutation, live provider/Telegram/notification sends, secret/credential movement, rotation, or disclosure, releases, tags, package publication, image publication, repository visibility changes or transfers, history rewrites, or force pushes without separate explicit operator approval.
