# Support

A2A Nexus is an alpha public-source project. Community questions and bug reports are welcome, but no production support, stability guarantee, release, package publication, or deployment approval is implied.

## Questions and usage help

Open a GitHub issue in `jinwon-int/a2a-nexus` using the most relevant issue template. Keep examples local-only and redact private endpoints, provider IDs, Telegram IDs, host paths, and credentials.

## Bugs

Use the Bug report template. Include local reproduction steps and redacted evidence only.

## Security issues

Do not open public issues for vulnerabilities. Follow `SECURITY.md` and use GitHub private vulnerability reporting when available.

## Unsupported requests

This repository does not authorize production deploys, service restarts, DB/outbox mutation, live provider/Telegram sends, secret movement, releases, package publication, repository visibility changes, history rewrites, or force pushes without separate explicit operator approval.
